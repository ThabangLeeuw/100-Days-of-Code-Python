# 🐍 Snake Game

A classic Snake Game built with Python's `turtle` graphics library.  
This project demonstrates object‑oriented programming, collision detection, and game loop logic in Python.

---

## 🎮 Features
- Snake movement controlled by arrow keys
- Food spawning at random positions
- Snake grows longer when food is eaten
- Scoreboard that tracks points
- Speed increases as score rises
- Game over detection when snake collides with walls or itself

---

## 🛠️ Technologies Used
- **Python 3**
- **turtle** graphics module (built‑in with Python)

---

## 🚀 How to Run
1. Clone or download this repository.
2. Make sure you have Python 3 installed.
3. Run the game with:

   ```bash
   python main.py
