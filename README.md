# Hangman Game 🎮

A classic Hangman game built in Python.  
This project demonstrates:
- Use of **modules** (`hangman_words.py`, `hangman_art.py`)
- **Randomization** with Python’s `random` library
- **Control flow** with loops, conditionals, and lists
- **ASCII art** for visual feedback

---

## Features
- Random word selection from a word list
- Lives system with ASCII hangman stages
- Tracks correct and incorrect guesses
- Prevents duplicate guesses
- Clear win/lose messages
