# Silent Auction 🎯

A simple Python program that simulates a silent auction.  
Participants enter their names and bids, and the program determines the highest bidder at the end.

## 📌 Features
- Collects bidder names and their bids
- Handles multiple bidders until no more participants remain
- Determines the winner with the highest bid
- Prints the winner’s name and bid amount

## Requirements
- Python 3.x
- Optional: `art` library for ASCII logo display
