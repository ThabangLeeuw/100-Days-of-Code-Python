# 🐢 Turtle Race Game

A fun Python project built with the `turtle` graphics library.  
Players bet on which colored turtle will win the race, then watch them race across the screen with random speeds.  

---

## 🎮 Features
- Six turtles, each with a unique color and name.
- User betting prompt: choose which turtle color you think will win.
- Randomized movement for each turtle, making every race unpredictable.
- Finish line detection with **winner announcement**.
- Handles **draw scenarios** if multiple turtles cross the finish line at the same time.
- Feedback on whether the user’s bet was correct.

---

## 🛠️ Requirements
- Python 3.x
- `turtle` module (comes pre-installed with Python)
