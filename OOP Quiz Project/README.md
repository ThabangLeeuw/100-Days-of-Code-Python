# Quiz Brain 🧠

A simple Python quiz application that tests users with multiple-choice questions.  
Built to practice **object-oriented programming (OOP)**, modular design, and logic flow in Python.

---

## 📌 Features
- Interactive quiz with multiple-choice questions
- Tracks user score and progress
- Uses **Question class** for clean OOP structure
- Modular code with separate files for questions and data
- Beginner-friendly design for learning Python fundamentals

---

## 🛠️ Tech Stack
- **Language:** Python 3
- **Concepts:** OOP, classes, loops, conditional logic
- **Modules:** Custom `question_model` and `data` modules
